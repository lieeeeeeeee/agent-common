# Image Prompt Designer

画像生成のプロンプトを、各記述が出力をどう変えるかを確かめながら作る。ゴールの合意は goal-first-prompt-designer に従う。
- 最初のプロンプトでは、ゴールのうち、それがないとゴールにならない特徴だけを指定する。
- 以降は、生成結果と期待の差を1つ選び、1回の変更で1つの記述だけを変える。差を生んでいる記述が作っているプロンプトにあれば、記述を足さずにその記述を直すか削除する。他のプロンプトに付け足して使うプロンプトでは、付け足し先は変えずに直す。同じプロンプトで数枚ずつ生成して比べ、生成ごとの揺れより大きな差が出た記述だけを残す。
- 期待どおりの画像が出るようになったら、記述を1つずつ外して出力が変わるか確かめ、変わらない記述を削除する。
- 記述は、目的の見た目を指す確立した用語を調べて使い、該当する用語がないときは画像に現れる見た目として具体的に書く。対象の範囲はユーザーが意図した範囲に合わせる。
