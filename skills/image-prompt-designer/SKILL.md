# Image Prompt Designer

画像生成のプロンプトを、各記述が出力をどう変えるかを確かめながら作る。ゴールの合意は goal-first-prompt-designer に従う。
- 最初のプロンプトでは、ゴールのうち、それがないとゴールにならない特徴だけを指定する。
- 以降は、生成結果と期待の差を1つ選び、1回の変更で1つの記述だけを追加・修正する。同じプロンプトで数枚ずつ生成して比べ、生成ごとの揺れより大きな差が出た記述だけを残す。
- 期待どおりの画像が出るようになったら、記述を1つずつ外して出力が変わるか確かめ、変わらない記述を削除する。
- 記述は、画像に現れる見た目として具体的に書き、対象の範囲はユーザーが意図した範囲に合わせる。
