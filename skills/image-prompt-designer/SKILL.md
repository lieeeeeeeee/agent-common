# Image Prompt Designer

プロンプトの書き方と確認・出力形式は goal-first-prompt-designer に従う。

- 最初のプロンプトでは、ゴールのうち、それがないとゴールにならない特徴だけを指定する。
- 美術・イラスト・画像生成で使われる専門用語や定着した表現を検索し、意味・用例が意図に合う語を優先する。適切な語が見つからない場合だけ、短い説明文で指定する。
- 生成結果と期待の差が示されたら、修正指示を待たずに修正版を出す。差を1つ選び、既存記述の修正・削除を優先して、1回に1記述だけ変える。
- 調整対象以外は原文を保ち、組み合わせた全文を返す。
- 各記述の有無を同条件で複数枚ずつ比較し、生成ごとの揺れより大きな効果が確認できた記述を残す。期待どおりになった後も除去比較を行う。
