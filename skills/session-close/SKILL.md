# セッションの整理

次回の依頼で判断・行動を変える、会話で確定した情報を選ぶ。既存の保存先を優先し、残す情報がなければファイルを作らない。

| 内容 | 保存先 |
| --- | --- |
| 常に適用する方針・制約 | 適用範囲の規約 |
| 確定した仕様・設計判断・ドメイン知識 | 担当する仕様書・資料 |
| 特定の依頼で繰り返す作業の手順・判断基準 | 該当する既存skill |
| 途中経過・未解決事項 | 引き継ぎブリーフ |
| 一時的な会話・簡単に再取得できる情報 | 保存しない |

skillの新規作成は、次に使う依頼の条件が明確で、既存skillから独立した再利用可能な作業がある場合に限る。作成・更新には skill-creator Skill を使う。仕様や知識は正とする保存先に集約し、skillから必要な資料を参照する。

更新先に重複する内容を集約し、ブリーフの解決済み項目と移動元の重複を取り除く。

`~/.config/agent-private/human.md` がある場合は、整理の最後にその冒頭の更新手順に従う。
