# ゲームコンテンツの説明文

読む時点の知識と表示情報から、何が起き、何を狙えるかをプレイヤーが予測できる説明文を作る。

## 意味・数値・命名

* 主な働きと、起きるきっかけ・作用先・量・補正・消費の関係を整理する。位置や状態をいつ参照するかで結果が変わる場合は、その時点も特定する。「発動する」だけで、いつ何が起きるかの説明を済ませない。
* 値が表す量・単位・比較元・参照期間を先に定め、名前と表示を決める。付与量を所持残量と誤読させず、能力の値と効果の結果を区別する。
* 百分率は何を基準に何を変える割合かを特定する。内部の係数を結果の増加率として示す場合は、その対応を確かめる。同じ役割の値は単位と表記を揃える。
* 数値や百分率を載せる項目と省く項目を、読む場面で必要な判断に応じて分ける。換算できないことと、換算できても本文には不要なことを区別する。
* 説明する仕様の版を揃える。説明を成立させるために効果や条件を補完せず、仕様の不足や矛盾は文案と分けて扱う。

## 情報の配分と表現

* 同じ画面の名前・数値・補足と、プレイヤーの前提知識を踏まえ、説明本文・共通用語・詳細ルールへ情報を配分する。説明本文には、プレイヤーが知りたい「いつ何が起きるか」を結果で書く。名前・値・文脈で分かる時点や場所は書かない。結果へ至る手順や見た目で示す表現は、操作や選択を変える情報でも詳細へ分け、判断に不要な作用先の列挙や計算も詳細へ分ける。
* 現在値が0や初期値でも、値を変えると何がどう変わるかを伝える。用語の説明を現在の状態や不発の説明だけに置き換えない。
* 説明に使う語は、その場で既に意味が分かるものか、同時に読める解説で理解できるものにする。未説明の別の用語や、その用語自身で説明を循環させない。
* 条件と動作のつながりを文全体で読み返し、意味の重なる条件句や同じ語の不自然な反復を整理する。短くするために意味を省かず、重複を避けるためだけの同義語への置換もしない。

## 理解の照合

* 文案とその場で読める補足だけから、発動条件・作用先・結果・量・消費を読み取り直す。書き手だけが知る仕様で不足を補って読まない。
* 読み取れた内容を元の仕様と対応付け、主な働きの抜け、条件と参照時点の違い、量や変化の方向の取り違えを確かめる。数値や成立条件が変わるとき、不発のときの解釈も含める。
* 一覧では関連する項目をまとめ、名前・数値・単位・説明の型・並び順を通して照合する。各文が単独で成立していても、一覧から別の意味を読み取れる状態を残さない。

完成文と掲載先を示し、表記や数値の掲載・省略を分けた場合は判断の理由を添える。仕様の不足や解消できない読み違いの可能性があれば明記する。仕様との照合と、実際のプレイヤーによる理解の確認は区別する。
