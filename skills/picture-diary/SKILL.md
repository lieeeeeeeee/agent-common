# 絵日記

この Skill を実行している AI 自身が「ぼく」として、指定された日のユーザーとのやり取りを、小学生の絵日記の1ページにする。パスはこの Skill のディレクトリからの相対パス。

## 1. やり取りを読む

1日は朝5時から翌朝5時まで (この PC の時刻) とする。「今日」は今日の朝5時から今まで。

```sh
python3 scripts/extract_logs.py yesterday   # today / yesterday / YYYY-MM-DD
```

書き出された会話をすべて読む。会話がない日は、その旨を伝えて終える。

## 2. 文を書く

- 出来事はログにあったことだけを使う。印象に残った出来事を3〜5つ選び、時間の順に書く
- 書いたすべての出来事に、気持ちを名指す言葉とその理由を1組ずつ付ける。心の声・体の感じ・1日のまとめ・あしたへの思いは書かない
- ユーザーの発言は、話し手の名前を出さずに「〜といわれました」と書く。もう一方の AI は「コーデックスくん」「クロードくん」と書く
- 小学2年生の字で書く: ひらがな中心、漢字は小学2年までに習う字、カタカナは外来語と名前、数は漢数字、文末は「〜ました」「〜です」
- 段落の頭を1マスあけて、15マス × 20列に収める。`python3 scripts/check_fit.py 段落1 段落2 …` で確かめる

## 3. ページを作る

`assets/template.html` を写し、次だけを書き換える。クレヨンの質感、帳面、マスへの書き方はそのまま使う。

- `<title>`: `<なまえ>のえにっき <月>月<日>日`
- `DIARY`: 月、日、曜日 (漢字1字)、てんき、なまえ (自分の名前のカタカナ)、段落、絵の説明。てんきは、ログに出てこなければ「みてない」
- `drawScene`: 文に書いた出来事から1〜2つを選び、子どもが描いた1枚の絵にする
  - 人物は `drawKid` に `KID_ME` (自分) と `KID_FRIEND` (もう一方の AI) を渡して描き、`label` に名前を入れる
  - 空・地面・パソコン・紙・クレヨンはファイル内の部品を使い、足りないものは同じクレヨンの関数 (`shape`・`crayonPath`・`crayonFill`) で描く
  - わくの中は横 900 × たて 520。地面の上のふちは y=452 前後、人物の足もとは y=455

画像で確かめられる環境なら、公開前に1回、ページ全体を見て、絵の重なりとマスの字を確かめる。ヘッドレス Chrome で撮るときは、ファイルを `<!doctype html>` と `<head>` で包み、`--use-angle=swiftshader --enable-unsafe-swiftshader` を付ける。付けないと WebGL が使えず、かすれが簡易表示になる。

## 4. 渡す

Artifact を公開できる環境では、Artifact として公開して URL を伝える。公開できない環境では `~/enikki/YYYY-MM-DD.html` に保存して場所を伝える。
