# Learn From Corrections

このセッションのやり取りから、次回の同種作業でユーザーに言われる前に行うべきことを洗い出し、反映先と文案を提案する。

## 入力

圧縮で失われた発言も対象にするため、このセッションの履歴ファイルからユーザーの発言をすべて読む。履歴ファイルは、Claude Code では `~/.claude/projects/` 配下の作業ディレクトリに対応するディレクトリに、Codex では `~/.codex/sessions/` 配下にある。最新の発言がこの会話と一致するファイルを使う。

## 洗い出し

- 対象は、明確になった用途や繰り返された依頼、指摘を受けて改めた行動とする。ドメイン知識は対象にしない。
- 同じ目的の依頼や指摘をまとめ、次回の同種作業で先に行う行動にする。
- 次のものは候補から外す。
  - 既存の規約・Skill ですでに定められている行動。ただし、同じ依頼や指摘が繰り返された場合は、既存の規定の書き換えを候補にする。
  - 規約を加えても防げない、一回限りの確認漏れ。
  - 特定の成果物の内容に限定された依頼や訂正。
  - セッション中に誤りと分かった指摘と、ユーザーが却下した提案。
- 反映先は、教訓が当てはまる範囲に応じて、共通の規約、プロジェクト固有の規約、該当する Skill の SKILL.md、特定の作業だけに当てはまる場合はその作業リポジトリ内のメモファイルから選ぶ。
- 既存の規則の書き換えで足りる場合は、規則を追加しない。

## 出力と反映

- 候補ごとに、根拠となる依頼・指摘、反映先、文案を示す。候補から外したものは1行にまとめて示す。候補がない場合はその旨だけを示す。
- ユーザーが採用した候補だけを反映する。合意前は書き込まず、コミットはユーザーの指示があるまで行わない。
