# イラスト制作（ローカルモデル風）

AI らしさを抑えたうえで、ローカルモデル風の今どきの絵柄にするためのルール。画像生成のプロンプトに追加して使う。

```text
## Style

Varied detail density, single focal point.

No idealized facial features. anime eyes, simplified fingers.
No photorealism, No intricate rendering.
No extraneous text, symbols, props or decorations.
```

迫力のある構図にしたい場合は、以下も追加する。

```text
### 構図

超広角の誇張パース.
解剖学的に成立するポーズで, 人体の一部だけフォアショートニング.
```

小物の色を引き立てたい場合は、以下も追加する。

```text
### 色使い

有彩色は小物に集める.
同種の小物は, 寒色から暖色へ色を移す.
アクセントカラーは1〜2点の小物にだけ使う.
非焦点領域は, 彩度を保ったまま暗い寒色に寄せる.
```

## 旧プロンプト（メモ）

```text
### 描写・画風

重厚で非写実イラスト。形態を大胆に単純化し、描写密度に強弱を設けて視覚的な焦点を一つに絞る。背景・小道具・衣装装飾などの非焦点領域は簡略化する。
必ず衣服の細部は抽象化する。

ハイコントラストな陰影表現。非焦点領域は大胆に明度を下げる。明部には無彩色のハイライトを用いる。単調なグラデーション、写実的な質感、過剰な光沢、油彩、黄ばみを避ける。

### 線画

Gペン風の繊細な細線と荒々しい太線が混在する、強弱のあるラフな線画。輪郭に細線を残し、細部は線より面の陰影で表現する。人物の線画は黒色を控え、有彩色で色トレスする。

### 目・顔

アーモンド形を禁止し、大きな団栗眼のタレ目を描く。正円の虹彩。まつ毛は透明度の高く色トレースする。涙袋の上に赤みを入れる。

顔立ちは非写実的に単純化し端正な顔立ちを避け、顔は小さくする。表情・ポーズは状況に合った自然で控えめなものにする。

未指定の文字・記号は追加しない。
指示がない限り腰から上のみ映す
```
