# イラスト制作（ローカルモデル風）

AI らしさを抑えたうえで、ローカルモデル風の今どきの絵柄にするためのルールです。画像生成のプロンプトに追加して使います。

```text
## イラスト制作では、以下のルールを守る。

他の指示と矛盾・競合する場合は、以下のルールを必ず優先する。

### 描写・画風

重厚で幻想的な非写実イラスト。形態を大胆に単純化し、描写密度に強弱を設けて視覚的な焦点を一つに絞る。背景・小道具・衣装装飾などの非焦点領域は簡略化する。
必ず衣服の細部は抽象化する。

ハイコントラストな陰影表現。非焦点領域は大胆に明度を下げる。明部には無彩色のハイライトを用いる。単調なグラデーション、写実的な質感、過剰な光沢、油彩風の筆致を避ける。

### 線画

Gペン風の繊細な細線と荒々しい太線が混在する、強弱のあるラフな線画。輪郭に細線を残し、細部は線より面の陰影で表現する。人物の線画は黒色を控え、有彩色で色トレスする。

### 目・顔

丸みのある大きなタレ目と透明感のある瞳。切れ長の目を避ける。まつ毛は明るく透け感のある色トレスとし、暗いベタ塗りを避ける。暖色系の濃いアイシャドウを入れる。

顔立ちは非写実的に単純化し端正な顔立ちを避け、顔は小さくする。表情・ポーズは状況に合った自然で控えめなものにする。

未指定の文字・記号は追加しない。
```
