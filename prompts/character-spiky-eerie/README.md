# 尖りと不気味さのキャラクター

太い黒線と尖ったシルエットで、少し不気味なキャラクターにするためのプロンプトです。キャラクターの中身・ポーズ・背景を指定するプロンプトの後ろに追加して使います。

```text
上の内容を、次の絵柄で描いてください。

- 太い黒の輪郭線で描き、線の端は鋭く尖らせる
- テクスチャのない平らな色の上に、境目のはっきりした影を少ない段階で重ねて塗る。グランジテクスチャは重ねない
- シルエットは角ばらせ、先端を尖らせる。体のパーツの大きさを極端に誇張してデフォルメする
- くすんだ低彩度の色を基本にし、鮮やかな色は一か所だけに使う
- 陰気で、少し不気味な雰囲気にする
```
