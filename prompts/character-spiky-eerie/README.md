# 尖りと不気味さのキャラクター

強弱のある黒線と尖ったシルエットで、少し不気味なキャラクターにするためのプロンプトです。キャラクターの中身・ポーズ・背景を指定するプロンプトの後ろに追加して使います。

```text
## 絵柄

- 強弱のある、画像に対して中細の角ばった黒線で、線の端は鋭く尖らせる

- バケツ塗りの均一な色面で陰影を明確にする。パーツごとに2色で塗る

- パーツは誇張してデフォルメする

- 顔は記号化する

- 小さく並ぶ部分は一塊で描く

- くすんだ低彩度の色をベースに、鮮やかな色は一か所だけに使う

- 陰気で、少し不気味な雰囲気にする

## 禁止事項

- テクスチャ
```
