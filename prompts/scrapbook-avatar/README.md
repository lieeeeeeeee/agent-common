# アバターと中の人の1枚絵

VRChat などのアバターと中の人の雰囲気を、1枚の画像で表すためのプロンプトです。中の人の写真を1枚目、アバターの画像を2枚目として ChatGPT に添付して使います。

```text
## キャラクター1

25歳前後の日本人女性OL。
ダークブラウンのストレートボブ、自然な斜め前髪。
ブラウンの瞳、ナチュラルメイク、清楚な顔立ち。
落ち着いた表情、華奢な体型。
ネイビーのテーラードジャケット、白いブラウス。

## キャラクター2

不思議の国のアリスをモチーフにした可憐な美少女メイド。
金髪の柔らかなウェーブヘア、繊細な前髪。
大きなサファイアブルーの瞳、長いまつ毛、ドールアイ。
白いレースのメイドカチューシャ、黒いリボン。
スカイブルーのフリルドレス、白いレースエプロン。
繊細なアイメイク、淡いピンクの頬、陶器のような肌。

## 構図

キャラクター1を中央に配置した正面バストアップ。
片手を目元に上げ、漫画パネルの先端を指先で軽くまむポーズ。
パネルは両目を覆う位置に配置。

## 漫画パネル

形状: 横長の非対称多角形。斜辺、鋭角・鈍角を組み合わせたダイナミックな変形コマ割り。矩形・平行四辺形を避ける。
輪郭: 太く明瞭な漫画風パネルボーダー。
内部描写 キャラクター2の目元をパネル形状でクリッピング。
外部描写 キャラクター1のデザインを維持。
位置合わせ 両キャラクターの目線・顔の角度・パースを一致。
重なり 指先とパネル端に自然な前後関係を設定。
```
