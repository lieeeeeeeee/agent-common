# アバターと中の人の1枚絵

VRChat などのアバターと中の人の雰囲気を、1枚の画像で表すためのプロンプトです。中の人の写真を1枚目、アバターの画像を2枚目として ChatGPT に添付して使います。

```text
1枚目の画像を編集して、人物が漫画のコマを目元にかざし、人物の横にもう1つ漫画のコマを置いた画像にしてください。

- 人物の顔・髪・服・背景・画風・構図は1枚目のまま保ち、1枚目に加える変更は、腕と手のポーズと2つのコマだけにする。
- ポーズ：片手を目元まで上げ、指先で目元のコマの端をつまんで、両目を覆う位置にかざす。
- コマの形：2つとも黒い太枠の漫画のコマで、辺の長さも角度もすべて異なる不規則な多角形。目元のコマは横長にする。
- 目元のコマの中：2枚目のキャラクターの目元を、2枚目の画風のまま描く。1枚目の人物の顔の向きに合わせて描き直し、コマの中の両目が、コマに隠れた人物の両目の位置にちょうど重なるようにする。
- 横のコマ：人物に重ならない位置に置き、中に2枚目のキャラクターの上半身を2枚目の画風のまま描く。
```
