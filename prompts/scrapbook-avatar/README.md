# アバターと中の人の1枚絵

VRChat などのアバターと中の人の雰囲気を、1枚の画像で表すためのプロンプトです。中の人の写真を1枚目、アバターの画像を2枚目として ChatGPT に添付して使います。

```text
1枚目の画像を編集して、人物が漫画のコマを目元にかざしている画像にしてください。

- 人物の顔・髪・服・背景・画風・構図は1枚目のまま保ち、変えるのは腕と手のポーズだけにする。
- ポーズ：片手を目元まで上げ、指先でコマの端をつまんで、両目を覆う位置にかざす。
- コマ：黒い太枠の漫画のコマ。形は横長の不規則な多角形で、辺の長さも角度もすべて異なる。
- コマの中：2枚目のキャラクターの目元を、2枚目の画風のまま描く。1枚目の人物の顔の向きに合わせて描き直し、コマの中の両目が、コマに隠れた人物の両目の位置にちょうど重なるようにする。
```
