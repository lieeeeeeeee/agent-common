# アバターと中の人の1枚絵

VRChat などのアバターと中の人の雰囲気を、1枚の画像で表すためのプロンプトです。中の人の写真を1枚目、アバターの画像を2枚目として ChatGPT に添付して使います。

```text
1枚目の画像を編集して、人物の目元・頭頂部・胸元の3か所に漫画のコマを重ねた画像にしてください。

- コマの外は1枚目のまま保つ。
- コマの形：3つとも黒い太枠の漫画のコマで、辺の長さも角度もすべて異なる不規則な多角形。目元のコマは横長で両目を覆う。
- 頭頂部と胸元のコマは、人物の髪と服がコマの周りに見える大きさにする。
- コマの中：コマが覆う部位と同じ2枚目のキャラクターの部位を、2枚目の画風のまま描く。1枚目の人物の向きに合わせて描き直し、コマの中の部位が、コマに隠れた人物の同じ部位の位置にちょうど重なるようにする。
```
