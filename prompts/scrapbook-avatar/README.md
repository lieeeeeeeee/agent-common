# アバターと中の人のスクラップブック

VRChat などのアバターと中の人を、1枚のスクラップブックのページにまとめるためのプロンプトです。中の人の写真を1枚目、アバターの画像を2枚目として ChatGPT に添付して使います。

```text
1枚目の写真の人物と、その人のアバターである2枚目のキャラクターで、スクラップブックのページを縦長で1枚作ってください。

- ページ：白い細い外枠で囲む。
- 中央：1枚目の人物を背景を除いて切り抜き、大きく配置する。顔・髪・服・ポーズは1枚目のまま保つ。
- 目元：2枚目のキャラクターの目元の切り抜きを、マスキングテープで人物の両目の上に貼る。キャラクターの目元は1枚目の人物の顔の向きに合わせて描き直し、切り抜きの中の両目が、隠れた人物の両目の位置にちょうど重なるようにする。
- まわりの切り抜き：2枚目のキャラクターの上半身、髪と髪飾りのアップ、衣装のアップの3枚を、大きさと縦横比がそれぞれ違う長方形にして、中央の人物のまわりに左右非対称に配置する。中央の人物はこれらより手前に重ねる。
- 飾り：2枚目のキャラクターのちびキャラのシール1枚、2枚目のキャラクターのモチーフのシール、マスキングテープ。色は2枚目のキャラクターの配色に合わせる。人物と切り抜きの中身が見えるように、飾りは四隅に貼る。
- 画風：人物は写真のまま、切り抜きは2枚目の画風のまま、シールとちびキャラはイラストで描く。
```
