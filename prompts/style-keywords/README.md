# 絵柄の指定語

## 組み立て方

修飾語、各分類の語、末尾の語の順に並べる。

- delicate + shoujo manga + art style → delicate shoujo manga art style
- 90s + anime + face → 90s anime-style face
- soft + painterly + digital painting → soft painterly digital painting
- natural + slice-of-life + atmosphere → natural slice-of-life atmosphere

画風の語に face を付けるときは `-style face` にする。
