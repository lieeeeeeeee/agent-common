# ざらつきと発光の背景画

ざらついた筆致で、暗がりに光源が光る背景画にするためのプロンプトです。場所・雰囲気・色を指定するプロンプトの後ろに追加して使います。

```text
上の内容を、人物のいない背景画として、次の絵柄で描いてください。

- デジタルペインティング。乾いた筆でこすったような、ざらついた荒いタッチで塗る。色を輪郭から少しはみ出させ、ところどころかすれさせる
- 画面全体に粗いフィルムグレインをかける
- 建物や家具の形とパースは正確に取る。張り紙や小物などの細部は描き込まず、色の塊として省略する
- 画面の大半を暗い影で沈め、光源のまわりだけを明るくして明暗差を強くする。光源は発光しているように描き、床や壁に落ちる光は輪郭のぼやけた抽象的な色の塊として塗る
```
