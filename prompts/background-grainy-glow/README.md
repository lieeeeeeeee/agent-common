# ざらつきと発光の背景画

ざらついた筆致で、暗がりに光源が光る背景画にするためのプロンプトです。場所・雰囲気・色を指定するプロンプトの後ろに追加して使います。

```text
上の内容を、人物のいない背景画として、次の絵柄で描いてください。

- デジタルペインティング。乾いた筆でこすったような荒く大きなタッチで、少ない手数で塗る。色を輪郭から少しはみ出させ、ところどころかすれさせる
- 明るさや色の変化は、滑らかなグラデーションを禁止し、少ない段階の平坦な色面を切り替えて表す
- 画面全体に粗いフィルムグレインをかける
- 形とパースは大枠だけ合わせる。線は定規を使わないフリーハンドで引く。細部は描き込まず、色の塊として省略する
- 画面の大半を暗い影で沈め、光源のまわりだけを明るくして明暗差を強くする。光源は発光しているように描き、床や壁に落ちる光は荒い輪郭の抽象的な色の塊として塗る
- 文字・記号は形を残さず、周りと同じ筆跡として塗る
```
