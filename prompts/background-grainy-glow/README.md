# ざらつきと発光の背景画

ざらついた筆致で、暗がりに光源が光る背景画にするためのプロンプトです。場所・雰囲気・色を指定するプロンプトの後ろに追加して使います。

```text
上の内容を、人物のいない背景画として、次の絵柄で描いてください。写真をなぞったような写実的な描写にはしないでください。

- デジタルペインティング。乾いた筆でこすったような、ざらついた荒いタッチで塗る。タッチは大きく、少ない手数で面を埋める。色を輪郭から少しはみ出させ、ところどころかすれさせる
- 明るさや色の変化は、滑らかなグラデーションにせず、少ない段階の平坦な色面を切り替えて表す
- 画面全体に粗いフィルムグレインをかける
- 建物や家具の形とパースは大枠だけ合わせる。線は定規を使わないフリーハンドで引き、揺れやかすれを残す。張り紙や小物などの細部は描き込まず、色の塊として省略する
- 画面の大半を暗い影で沈め、光源のまわりだけを明るくして明暗差を強くする。光源は発光しているように描く。光・影・映り込みの形は、光源の位置から正確に計算せず、平坦な色面の配置として決める。床や壁に落ちる光は荒い輪郭の抽象的な色の塊として塗る
```
