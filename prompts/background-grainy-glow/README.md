# ざらつきと発光の背景画

ざらついた筆致で、暗がりに光源が光る背景画にするためのプロンプトです。場所・雰囲気・色を指定するプロンプトの後ろに追加して使います。

```text
上の内容を、人物のいない背景画として、次の絵柄で描いてください。

- 乾いた筆でこすったような、かすれの残る荒く大きなタッチで、少ない手数で塗る。色を輪郭から少しはみ出させる
- 明るさや色の変化は、滑らかなグラデーションを禁止し、少ない段階の平坦な色面を切り替えて表す
- 粗いフィルムグレインをかける
- 形とパースは大枠だけ合わせる。細長い物も線で引かず、周りと同じ筆跡で塗る。タッチより小さい形は描き込まず、周りとまとめて塗る
- 画面の大半を暗い影で沈め、光源のまわりだけを明るくして明暗差を強くする。光源は発光しているように描き、落ちる光は荒い輪郭の色の塊として塗る。反射は乾いた筆でこすって置く
- 暗部は重なる物の明るさを一段ずらす
- 文字・記号・図表は形を残さず、周りと同じ筆跡として塗る
```
