# 犬の写真のLINEスタンプ

犬の写真から、デフォルメしたゆるい手描きのLINEスタンプを1個作るためのプロンプト。ChatGPT に犬の写真を添付し、共通部分の後ろに絵柄を1つ追加して使う。

## 共通部分

```text
添付した写真の犬を、LINEスタンプ1個分のイラストにする。

- 犬: 写真の犬1匹。毛色・模様・耳の形・目の色は写真のまま残す
- 文字: 「ありがとう」の5文字だけを、横書き1行で大きく入れる
- 仕上げ: 犬と文字を太い白フチで囲み、背景は透過する。画像は正方形
```

## 絵柄

### ゆる手描き

力の抜けた絵で、毎日使いやすくする。

```text
## 絵柄

- デフォルメ: 犬を丸いおもちのような形に単純化する。目は黒い点、口は短い線
- 線: 少し揺れた、黒いペンの手描きの線
- 塗り: 写真の毛色を1〜2色だけ使ったベタ塗り。陰影はつけない
- 文字: 太めのペンで書いた、丸みのある黒い手書き文字
```

### 写真寄り

線と塗りだけをゆるくして、体つきは写真に近く残す。

```text
## 絵柄

- デフォルメ: 体つきと顔つきは写真に近いまま、形を少し丸くする程度にとどめる。目は黒い点、口は短い線
- 線: 少し揺れた、黒いペンの手描きの線
- 塗り: 写真の毛色を1〜2色だけ使ったベタ塗り。陰影はつけない
- 文字: 太めのペンで書いた、丸みのある黒い手書き文字
```

### クレヨン

子どもの落書きのような素朴な味にする。

```text
## 絵柄

- デフォルメ: 犬を丸いおもちのような形に単純化する。目は黒い点、口は短い線
- 線: クレヨンで描いた、かすれのある太い線
- 塗り: 写真の毛色のクレヨンで、線から少しはみ出すように塗る。塗りムラを残す
- 文字: クレヨンで書いた太い手書き文字
```

### 線なし

色の面だけで描いた、やわらかくおしゃれな印象にする。

```text
## 絵柄

- デフォルメ: 犬を丸いおもちのような形に単純化する。目は黒い点、口は短い線
- 線: 輪郭線は描かず、色の面の境目で形を表す
- 塗り: 写真の毛色を1〜2色だけ使ったベタ塗り。陰影はつけない
- 文字: 丸みのある黒い手書き文字
```

### ずらし塗り

雑貨のようなおしゃれさを出す。

```text
## 絵柄

- デフォルメ: 犬を丸いおもちのような形に単純化する。目は黒い点、口は短い線
- 線: 少し揺れた、黒いペンの手描きの線
- 塗り: 写真の毛色を1〜2色だけ使ったベタ塗りを、線から少しずらして置く。塗りに粗い紙のようなざらつきを入れる
- 文字: 線と同じペンで書いた手書き文字
```

### ヘタウマ

わざと崩した形で、おかしさと愛嬌を出す。

```text
## 絵柄

- デフォルメ: 形を少しいびつにする。目は離れた2つの点、手足は短い棒
- 線: 太い黒マジックで一気に描いた線
- 塗り: 写真の毛色を1色だけ使い、ざっくりベタ塗りする
- 文字: 黒マジックで書いた太い手書き文字
```
